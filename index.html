Heimdall

The demoable version of my patent-filed idea for stopping Harvest-Now-Decrypt-Later attacks. Heimdall watches the cloud control plane, scores every CloudTrail event through four detection pillars and four ML models, and boils it down to one security posture score. When a bulk copy looks like a harvest, an agent investigates and plans a containment that, after human approval, actually executes on AWS. Demoed live on a real account, not a simulation.

An AI-based post-quantum readiness platform that helps enterprises meet CNSA 2.0 mandates and catch Harvest-Now-Decrypt-Later attacks early. Runs multi-dimensional audits across cloud infrastructure, live network protocols (handshake and cipher-suite negotiation), and code binaries using taint analysis - using reinforcement learning to help generate CBOMs with AI-based confidence checks.
